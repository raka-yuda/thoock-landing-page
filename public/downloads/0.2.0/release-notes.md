Thoock 0.2.0 — release preview

- Move images, opportunities, briefs, and export history to recoverable Trash. Inspect storage usage, configure conservative cleanup, and remove workspace export copies.
- Back up, restore, or reset a workspace with visible processing progress and cancellation. Reset keeps device preferences, downloaded models, and vault credentials; keys are never included in backups.
- Create transparent PNG cutouts locally with an optional BiRefNet model download. Preview edits, preserve originals, and export transparent images as PNG. Glass and fine translucent details may need manual refinement.
- Start from a task-focused dashboard and an optional setup guide for provider connections and first imports.
- Use searchable floating selectors, compact row-action menus, sticky settings navigation, and focused settings sections.
- Check for new releases from About & updates. Startup checks are optional; downloads open in the browser and installation remains manual.
- Improve storage refreshes and provider-log paging, check available disk space, reconnect device vault references after recovery, and offer startup/rendering recovery instead of a blank screen.
- Add reproducible media benchmarks through 10 GiB of generated 4K originals. The largest run verified fresh-workspace restore; full-size rollback replacement and Windows runtime performance remain untested.

Availability: Apple silicon macOS and Windows x64 preview installers. macOS is ad hoc signed, not notarized; Windows is unsigned and has not been installed or run on Windows. Local background removal requires macOS 13.3 or later. Intel Mac builds are not included.

Before updating, save a workspace backup and close Thoock. Install the new app over the previous version. Workspaces are separate from the installer; keeping an older installer does not roll back migrated workspace data. Restore a compatible backup if returning to an older app.
